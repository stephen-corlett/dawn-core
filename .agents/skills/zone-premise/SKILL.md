# Zone premise

You're doing gate 1 of the zone pipeline. You can't ask anyone anything, and you can't see any
earlier conversation, so work only from the request you were given and the repository.

Read these first:

- [docs/zone-pipeline.md](../../../docs/zone-pipeline.md), especially "Which order"
- [docs/world/bible.md](../../../docs/world/bible.md)
- [docs/world/atlas.md](../../../docs/world/atlas.md), and the briefs of neighboring zones
- [docs/art/bible.md](../../../docs/art/bible.md)

## Steps

1. If the brief doesn't exist, copy `docs/world/zone-template.md` to `docs/world/zones/<name>.md`,
   and put the request in the Premise section, in its original words.
2. If the brief's Decisions don't name a premise, write three that are really different from each
   other, in your log entry. Each gets a few lines: its theme, three to five threads that stand
   alone, what happened here, and the sight a player would remember. A theme is what life is like
   here, not a plot, so don't build a zone around one mystery. Fit the scale to the place, as "Zone
   themes" in the world bible says. Follow the brief's Decisions, and don't reuse a rejected idea.
3. If a premise has been chosen, fill in the Premise section from it. Keep it to a page. This is
   the seed of the terrain and quests, not a lore document.
4. For each history event, name what it left on the land. A history that changes nothing a player
   can see doesn't belong here.
5. Add a gate log entry, and propose the zone's atlas row in it. `zone-design` updates the atlas
   once a person agrees.

## Report

Report **Needs decision** with the brief's path and the options or finished premise. A person
passes this gate, so never report **Passed**.
